# 대끼리네

- **부산 맛집 공유 웹/앱**
- **부산 현지인&부산을 방문하는 관광객 특화**

## 개요

- 2025년 부산 방문 외국인 관광객 수가 300만 명을 돌파하면서, 부산은 본격적인 글로벌 관광도시 단계에 진입하였다.
- 2024년 부산 방문 내국인 관광객 1,063명 및 외국인 관광객 1,060명을 대상으로 한 실태조사에서, 여행 목적 중 ‘맛집 탐방’ 응답 비율이 각각 81.7%, 81.3%로 매우 높게 나타났다.
- 한편 실제 주요 관광활동에서는 자연풍경 감상이 가장 높은 비중을 차지하고 그 다음으로 맛집 탐방 수요가 이어져, 자연·해변 등 주요 관광지와 지역 맛집 간 연계의 필요성 또한 존재한다.
- 이에 본 서비스는 주요 관광지 주변에서 부산 현지인이 인정하는 맛집을 추천하고, 관광객이 이를 기반으로 방문·평가할 수 있는 플랫폼을 구축함으로써, 관광지와 맛집 사이의 동선·정보 연계성을 극대화하고자 한다.

## 기능

- 홈
    - 가게 이름/요리 종류 검색창 띄우기
    - 전체/요리 종류/주요 관광지 주변 인기 많은 맛집 표시
    - 음식 종류별로 인기많은 맛집 표시
- 게시물
    - 추천 가게 등록/삭제/수정
        - 등록 항목 : 먹은 메뉴, 식당 이름, 리뷰(선택), 별점(선택), 간 사람 수(선택), 가격(선택), 어떤 면이 좋았는지 카테고리,  어느 관광지와 가까운지 추천
    - 추천 가게 당 추천수, 별점 평균, 리뷰 수 표시.
    - 등록된 메뉴 개수 & 평점을 비교하여 대표 메뉴로 표시
    - 가는 법/지도로 위치 제공
        - 일단 주소, 지도 링크로 간단하게
        - 할 수 있다면 소요시간도 제공한다.
- 회원가입 페이지 - Spring Security System + JWT(Refresh 이용)
    - 닉네임 입력
    - 비밀번호 찾기용 이메일 입력
    - 아이디/비밀번호 입력
    - 현지인/관광객 구분
- 로그인 페이지 - Spring Security System + JWT(Refresh 이용)
    - 아이디/비밀번호 입력 기반
    - OAuth도 이용
- 추가 기능
    - 홈에서 날씨에 걸맞는 음식 추천
    - 위치 정보를 얻어 현재 위치에서 가까운 맛집 추천
    - 시간대에 따른 밥집/술집/디저트 위주 추천
    - 소거적 추천(싫어하는 것을 거른 것 추천)
    - 맛집 근처의 관광지도 추천해주는 기능
- 관리자 기능
    - 관광지-맛집 조합의 통계 확인
    - 이용자 외국인/내국인 비율 확인
    - 해당 가게와 관련성이 적은 리뷰/지나친 악성 리뷰는 신고를 받아 관리자 권한에서 삭제하도록 함.
- 마이페이지 기능
    - 하루 동안 갈 관광지 목록을 미리 적어두면, 이에 관한 맛집들을 추천하여 마이페이지에 저장할 수 있도록 함 → 캘린더 API 이용, 해당 칸에 기록. 이를 바탕으로 추천하게 한다.
    - 사용자가 맛집 즐겨찾기를 따로 등록하여 저장할 수 있게 함.
